# АТА Энерго

Рабочий интерфейс CRM использует общую навигацию, русские подписи и существующие темы приложения. Цвета, типографика, карточки и состояние фокуса определены в `web/src/styles.css`.

«Склад и архив» открывается из бокового меню. Склад начинается с запчастей и остатков, архив — с заказ-нарядов. На широком экране разделы сгруппированы по источнику в боковом указателе. На узком экране используется системный список разделов. Число записей видно при выборе раздела. Заголовок раздела напоминает складскую этикетку с отдельным счётчиком и использует акцент текущей темы. Названия набираются Inter, счётчики и остатки — JetBrains Mono.

Одновременно раскрывается одна запись. Ключевые значения видны над полной сеткой полей, которая перестраивается по ширине. Архивные фотографии загружаются при раскрытии записи. Раздел и страница сохраняются в URL.
