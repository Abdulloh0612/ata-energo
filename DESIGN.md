# АТА Энерго

Рабочий интерфейс CRM использует общую навигацию, русские подписи и существующие темы приложения. Цвета, типографика, карточки и состояние фокуса определены в `web/src/styles.css`.

Архив открывается из бокового меню. Список источников показывает число записей в каждом разделе. По умолчанию видны названия и остатки запчастей. Раскрытие строки показывает все доступные поля и фотографию, если она есть. На узких экранах поля переносятся в одну колонку.
