# Локальный агент на объекте

Агент нужен, когда инвертор доступен в локальной сети клиента. Программу запускают на компьютере рядом с оборудованием. Она сама устанавливает исходящее соединение с сервером CRM, забирает задания и передаёт результаты.

1. **Зарегистрируйте агента.** На сервере с Docker Compose выполните команду ниже, подставив адрес CRM, доступный с объекта. Команда создаёт запись агента и один раз выводит токен.
2. **Установите программу на объекте.** Скопируйте каталог `agent/` со всеми его модулями. В этом каталоге установите зависимости Python и запустите агент с выданным токеном.
3. **Проверьте связь.** После регистрации агент выводит своё имя и сообщение об ожидании задач. Его последний контакт и возможности видны в CRM. При повторном запуске достаточно `python ata_agent.py`: настройки сохраняются рядом со скриптом в `agent_config.json`. Этот файл содержит токен.
4. **Подключите устройство.** В разделе поиска выберите агента, запустите поиск и откройте найденный инвертор. Запустите проверку чтения показаний. После успешной проверки выберите клиента и подключите устройство. Показания появятся после очередного опроса.

**На сервере CRM**

```bash
docker compose exec app ./cmd/createagent -server https://crm.example.org "Офис"
```

**На компьютере клиента, из каталога агента**

```bash
python -m pip install -r requirements.txt
python ata_agent.py --server https://crm.example.org --token "<токен агента>"
```

| Симптом | Что проверить |
|---|---|
| Агент сообщает об ошибке соединения | С компьютера на объекте должен открываться фактический адрес CRM. Адрес `localhost` на таком компьютере ведёт к нему самому. |
| Сервер ответил `401` | Проверьте токен и активность агента. При перевыпуске используйте новый токен на объекте. |
| Устройство найдено, но показаний нет | Посмотрите результат проверки протокола, наличие привязки к модему и время последнего контакта агента. Для Bluetooth также проверьте доступность адаптера на компьютере. |

Как связаны задания, результаты поиска и модемы, показано в [справочнике базы](DATABASE.md). Параметры запуска определены в [программе агента](../agent/ata_agent.py).
