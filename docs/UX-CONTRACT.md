# Поведение CRM

| Capability | Canonical owner | Source of truth | Allowed variants | Verification |
|---|---|---|---|---|
| Select/Listbox | Нативный select | Формы CRM | Фильтр и выбор в форме | Клавиатура и мобильный экран |
| Date | Нативные поля даты и срока | API принимает дату или момент с часовым поясом | Сервис, срок, период графика | Редактирование и повторное открытие |
| Form | Формы функций и api в core.tsx | Серверные ограничения полей и операций | Вход, мастер, карточка | Ввод, ошибка сервера, отправка |
| Scrollbar | web/src/styles.css | Тема рабочего пространства | Основная область и прокрутка таблиц | Узкий экран |
| Toast | Toasts в ui.tsx | Событие ata:toast | Сохранение и аварии | Роль status и настройки профиля |
| CRUD | Обработчики Go и TanStack Query | API и возвращённые права | Список, карточка, боковая панель | Запись и чтение после обновления |

Параметры URL определяют выбранную запись и фильтры. Для чувствительных действий назначение и права проверяет сервер. Обращения клиента ограничены его учётной записью. Сетевые ошибки отображаются у действия; сохранение подтверждается ответом сервера. Закрытие вкладки завершает её локальную JWT-сессию.

Дашборд станции открывается внутри её карточки. Вкладки, периоды и выбранные серии работают в памяти страницы. Название объекта фиксировано внутри карточки. Переходы к клиенту и локальному оборудованию меняют URL на их карточки. Для облачного оборудования без локальной привязки схема открывает вкладку показателей. Самостоятельный HTML содержит mock-объект, режим CRM получает данные через адаптер страницы. Адаптер проверяет origin и окно отправителя сообщений, передаёт только данные визуализации. История запрашивается в часовом поясе объекта, верхняя граница дневных и месячных диапазонов Deye исключается. Контракт API описан в `API.md`.

Нажатие на инвертор во вкладке устройств открывает его подробные измерения внутри той же станции (`?inverter=ID`). Возврат сохраняет вкладку устройств. Устройство проверяется по списку оборудования этой станции на сервере. Автоматическое обновление показателей, истории и аварий — раз в 180 секунд; ручное обновление доступно отдельно. История выбранных параметров Deye загружается порциями до пяти ключей с объединением по времени. Отсутствующие измерения не заменяются нулями. CSV содержит текущий набор данных. Схема учитывает направление мощности и настройку уменьшения анимации.

ValueClouds использует те же дашборды станции и инвертора. Подключение аккаунта
доступно администратору в разделе «Интеграции»; после сохранения запускается
синхронизация, её ошибка отображается в списке аккаунтов. При редактировании
пустые поля логина и пароля сохраняют прежние значения. Пароли скрыты по
умолчанию, переключатель раскрытия доступен с клавиатуры. Суточный выбор
параметров графика ограничен рядами мощности, предоставляемыми ValueClouds.
Остальные измерения доступны в карточке. Контракт и ограничения источника:
[INTEGRATIONS.md](INTEGRATIONS.md#valueclouds).

Карточка ValueClouds сохраняет принадлежность измерения к группе производителя
и исходный ключ для CSV. Читаемая подпись используется в интерфейсе. Нулевые
мощности отображаются как нули. Активные параметры, их время обновления и
паспорт логгера видимы непосредственно в карточке; полный набор измерений
доступен независимо от настроек видимости в портале производителя.

Пустые блоки инвертора (BMS, генератор, AC, версии и другие) скрываются для
всех источников по фактическому наличию измерений, а не по названию провайдера.
Сводные показатели сопоставляются с общими названиями и единицами; исходные
ключи и значения CSV сохраняются. Значения `0` и `0%` видимы. Отсутствие поля
не заменяется нулём; при поиске без совпадений показывается явное сообщение.
