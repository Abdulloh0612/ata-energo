# Hybrid Doctor в Ата Энерго

CRM автосервиса открывается из меню сотрудников и напрямую по адресу
`/hybrid-doctor/`. Вход выполняется с учётной записью Hybrid Doctor.
AtaEnergo обслуживает этот путь внутри контейнера `app`.
Его HTML, статика, API, ссылки гарантии и PWA используют один и тот же префикс.

## Данные и запуск

Для нового стенда Compose создаёт пустую рабочую базу при первом запуске.
Для переноса запустите импорт до первого запуска AtaEnergo, из корня репозитория:

```sh
python3 hybrid-doctor/import_data.py /path/to/hybrid.db --photos /path/to/photos
docker compose up -d --build
```

Импорт копирует SQLite и каталог фотографий в `hybrid-doctor/data/`, проверяет
целостность и наличие файлов, сохраняет учётные записи и сбрасывает сеансы.
После переноса сотрудники входят заново со своими паролями. Импорт прерывается,
если целевой каталог уже существует. База, фотографии и новые ежедневные
резервные копии хранятся в этом каталоге, исключённом из Git и сборки образов.

Если прежний контейнер автосервиса запускался в этом же Compose-проекте,
при обновлении используйте `docker compose up -d --build --remove-orphans`.

При пустой базе создайте первого владельца внутри запущенного контейнера:

```sh
docker compose exec app python3 hybrid-doctor/app.py create-owner "Имя" admin
```

Для HTTPS укажите `HD_SECURE_COOKIE=1` в `.env`. Nginx должен передавать
`Host` и `X-Forwarded-Proto` и разрешать тело запроса до 25 000 000 байт
на пути `/hybrid-doctor/`. PWA устанавливается по HTTPS или с localhost.

Для локального запуска установите Python 3.9+ в Linux и запустите AtaEnergo через `make run` из корня репозитория. Vite передаёт запросы к модулю Go-серверу на порт 8000.
